## Steinteppich Wand verlegen: Schritt für Schritt erklärt

Das [**Steinteppich Wand verlegen**](https://ds-steinteppich.de/steinteppiche-verlegen) unterscheidet sich deutlich von der Bodenmontage. Da das Material an senkrechten Flächen haftet, muss eine spezielle Standfestigkeit erreicht werden.

1. **Untergrund vorbereiten:** Der Untergrund muss trocken, sauber und tragfähig sein. Eine passende Grundierung sorgt für optimalen Halt.
2. **Bindemittel anmischen:** Für die Wandmontage wird ein spezielles, standfestes Bindemittel (oft auf PU- oder Epoxidharzbasis) verwendet.
3. **Masse auftragen:** Das Gemisch aus Kieselsteinen und Harz wird gleichmäßig mit einer Glättkelle angedrückt und geglättet.
4. **Porenschmelze / Versiegelung (optional):** In Feuchträumen empfiehlt sich ein Fugenfüllstoff, um die Fläche absolut wasserdicht zu machen.
